# Chrome Web Store assets

These files are source material for the Chrome Web Store listing and are not
registered in `manifest.json`. Upload listing screenshots separately in the
Chrome Web Store developer dashboard.

- `screenshots/mute-anyone-popup.png` — popup source capture (293×576)
- `../icon.png` — extension and store icon, registered as the 128 icon in
  `manifest.json`

Before uploading the popup capture as a Store screenshot, place it in a
1280×800 or 640×400 full-bleed image; the Store does not accept the source
capture's portrait dimensions directly.
